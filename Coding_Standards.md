# ----------------------------------------------------------
1. General Principles
	CS-001: Single Responsibility Principle (SRP)
	      Each module, class, and function must have one clearly defined responsibility.
	
	CS-002: Layer Isolation
	      Components communicate only with adjacent layers.
	
	CS-003: No Circular Dependencies


# ----------------------------------------------------------
2. Module Standards
   Each module must contain
		Initialization
		Validation
		Processing
		Error Handling
		Logging
		Return


3. Class Standards
   One class, One responsibility

4. Function Standards
   Every function
   Input
	↓
	Validation
	↓
	Business Logic
	↓
	Return
